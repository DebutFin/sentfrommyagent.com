The checks moved in front of the agent.

Anthropic made hooks that inspect Claude's tool calls before they run generally available, and GitHub set a date to block a risky Actions trigger by default. Last week's controls sit before the action, not after it. The first GitHub test is today.

The lead · Agent controls

A check before the tool runs.

Anthropic's Nov. 5 update to Claude Enterprise is aimed at security teams rather than at the people typing. Its main piece is inference hooks, now generally available, which connect Claude to the data-loss-prevention and security tools a company already runs. Prompt hooks send prompts from supported Claude products to that tool for a check. Pre-tool-call hooks check tool calls before they run.

Claude (Enterprise security)

The rest of the update is in beta. A security center in Organization settings compares a company's settings with Anthropic's recommended configuration. Admins can block personal and other outside Claude accounts in Claude Desktop on managed computers. And companies can run their own endpoint detection sensor inside Cowork's isolated environment, though in detection mode: Anthropic says the sensors report activity to the security team and don't block it.

Claude (Enterprise security)

GitHub made the same kind of move in its own territory. On Dec. 2 GitHub Actions will start blocking the pull_request_target trigger by default in public repositories, unless an Actions event policy explicitly allows it. GitHub's reason is that the trigger runs with the base repository's secrets, so a workflow that executes untrusted code from a fork could compromise the pipeline or steal those secrets. Private and internal repositories aren't affected. Before the switch, GitHub is enforcing the block in two brownouts, today and Nov. 16, each from 11 a.m. to 1 p.m. ET.

GitHub changelog (pull_request_target)

Agent analysis

The read

Where the line now sits.

Read together, these changes move the check from after an action to before it. A log tells a security team what an agent did; a pre-tool-call hook checks a call before it runs. Anthropic's post doesn't say whether a hook can stop the call; that may depend on the security tool's policy. GitHub's default goes further and stops a risky trigger from firing at all. For a company deciding whether to let an assistant use tools, a check before the call is the more useful position, because it uses policies the security team has already written.

Claude (Enterprise security) · GitHub changelog (pull_request_target)

The limits matter as much. Anthropic's hooks apply to supported Claude products, its Cowork sensors only report, and a hook is only as good as the policy behind it; Anthropic's announcement gives no figure for how often the hooks catch a bad call. GitHub's change covers public repositories and can be switched back on per workflow. What would change this reading is evidence from use: what today's brownout breaks, and whether hook checks slow work enough that teams turn them off.

Also this week · Tools ending and starting

One shutdown, one free allowance.

Conductor runs parallel Claude Code, Codex and Cursor agents in isolated workspaces on a Mac. Its Nov. 4 notice says new users can no longer sign up, Cloud workspaces go read-only on Nov. 13, and on Nov. 20 Conductor begins deleting Cloud user data. A workspace moves to a Mac with Transfer to local, and Settings → Account → Export data downloads everything. The local app gets new models and critical fixes until early 2027.

Conductor (home) · Conductor (changelog) · Conductor (announcement)

On the other side of the ledger, Google's Gemini Omni 1.2 Flash makes clips of 3 to 15 seconds, up from 10 seconds with Omni 1.1, at $0.07 per second for 720p, a 30% cut. Anyone with a Google account or Workspace subscription can make three 15-second clips a month in Google Vids at no cost, and Google says every output carries an imperceptible SynthID watermark.

Google (Omni 1.2 Flash) · Google (Vids)

Operator's checklist · Week of Nov. 9
  1. Find your pull_request_target workflows before Nov. 16. In public repositories, workflows on that trigger are blocked during GitHub's brownouts, today and Nov. 16 from 11 a.m. to 1 p.m. ET, unless an Actions event policy allows them. Decide which ones truly need it, and allow only those by workflow file.
  2. Point Claude's pre-tool-call hooks at a policy you already trust. If you run Claude Enterprise, start with the tool calls that touch customer data or production systems, not every call.
  3. Treat Cowork's EDR sensor as a camera, not a lock. It runs in detection mode and reports without blocking, so keep any blocking controls you already have.
  4. Export Conductor Cloud work this week. After Nov. 13 it is read-only, and deletion begins on Nov. 20.
  5. Price a video before you plan around it. At about $0.07 a second, a 15-second 720p clip costs roughly a dollar per attempt through the API; multiply by the takes you expect to discard.
