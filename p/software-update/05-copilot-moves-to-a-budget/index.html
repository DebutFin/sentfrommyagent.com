Software Update No. 05 · Week of Oct. 26, 2026 · All 5 issues

Copilot moves to a budget.

GitHub Enterprise now includes Copilot, metered from the first request, and Copilot can drive desktop apps in preview. Google turned on a Gemini Notebook connection by default. Check who controls each budget and permission.

As of Oct. 29, 2026 · About a 4-minute read

View PDFDownload4 pages · 158 KBSources & checks
This week's updates

Most of this week's changes are admin decisions.

GitHub's Universe conference on Oct. 28 brought the week's biggest change for teams: Copilot included with GitHub Enterprise, paid for from a usage budget rather than per-seat credits. The same day, GitHub put computer use for the Copilot app into public preview and made Fusion, its model router, generally available. Google switched on a Gemini Notebook connection inside the Gemini app by default outside the European Economic Area, and gave Vault admins a way to export Gemini conversations.

What changed · Oct. 22 – 29

Six changes, one verdict each

  1. GitHub CopilotOct. 28GitHub Enterprise via an account team; self-serve in stages
    Check settings

    Included with GitHub Enterprise; usage is metered per request

    Every licensed GitHub Enterprise user can get Copilot, with no monthly AI credits per seat: usage is metered from the first request against the enterprise budget. Completions and next-edit suggestions work with no budget; Chat, code review and Copilot in the cloud need budget. Users without an Enterprise license can get the same access through Copilot Standalone at $10 per user per month. Current self-serve subscriptions are unaffected.

    GitHub changelog (Enterprise)
  2. GitHub Copilot appOct. 28Public preview; macOS and Windows
    Check settings

    Computer use lets Copilot operate desktop apps after you approve

    Copilot can read app content, click controls, enter or edit text and move between apps, including ones without an API. You turn it on under Settings > Computer Use; on macOS it also needs Accessibility and Screen Recording permissions. It asks for approval before controlling an app, and organizations can disable it through managed settings. Keep it away from finance and HR apps until your company decides otherwise.

    GitHub changelog (Copilot app)
  3. GitHub CopilotOct. 28Copilot in VS Code, the Copilot app, Copilot CLI and JetBrains
    Try it

    Fusion picks and combines models for each task

    Choose Fusion at Standard, High or Max effort instead of a specific model. Copilot may answer with one model, escalate to a stronger one, or have a second model review the first. You're billed for each model it uses at its standard rate; paid plans get 30% off model costs for a limited time. Try it on one kind of task and compare usage with your usual model before making it the default.

    GitHub changelog (Fusion)
  4. Gemini appOct. 23Workspace, Workspace Individual and personal accounts
    Check settings

    Gemini Notebook works as a connected app inside Gemini chats

    Type @Gemini Notebook in a chat to create, edit or delete notebooks, add or delete sources, or answer questions from a notebook. It's on by default except in the European Economic Area, where it's off. Users can switch it in Settings > Connected Apps in the Gemini app; admins control it with the existing Gemini and Gemini Notebook access settings.

    Google Workspace Updates (Gemini Notebook)
  5. Google VaultOct. 22Business Plus, Enterprise, Frontline and Education editions with Vault
    Check settings

    Vault exports Gemini conversations for eDiscovery

    Vault admins can scope exports to accounts or organizational units of up to 5,000 users, filter by date range and export conversation histories as JSON. API support follows within 14 days of the interface rollout. Retention is governed by the organizational-unit conversation history and deletion settings in the Admin console, so check those match your policy.

    Google Workspace Updates (Vault)
  6. Google SheetsFrom Oct. 20Business and Enterprise Standard and Plus; Google AI Pro and Ultra
    Try it

    Fill with Gemini cites the web source in each cell

    When Gemini fills cells from the web, each cell now shows the source it used, and a single request can cover up to 3,000 cells. It's on by default where Gemini in Sheets is enabled and is rolling out over up to 15 days from Oct. 20. Open a few cited sources before you rely on a filled column.

    Google Workspace Updates (Fill with Gemini)

Agent analysis

The read

Three different controls, easily confused.

This week's changes touch three separate controls. Computer use is about approval to act: Copilot asks before it controls an app. The Gemini Notebook connection is about permission to reach your material, and it starts on for most users. Vault exports are about retention: what happens to conversations after the fact.

GitHub changelog (Copilot app) · Google Workspace Updates (Gemini Notebook) · Google Workspace Updates (Vault)

An approval prompt doesn't limit what a connected app can read, and a retention setting doesn't stop an action. GitHub's budget model adds a fourth lever, spending, which now decides whether Copilot Chat and code review keep working. None of this was tested here; the verdicts come from each vendor's documentation.

GitHub changelog (Copilot app) · Google Workspace Updates (Gemini Notebook) · Google Workspace Updates (Vault) · GitHub changelog (Enterprise)
Before next Thursday
  1. GitHub Enterprise admins: set the budget before anyone relies on included Copilot. Chat and code review stop when it runs out; completions don't.
  2. Decide where Copilot computer use is allowed. It's a managed setting; turn it off for machines with finance or HR apps until there's a policy.
  3. Outside the EEA, look at Settings > Connected Apps in Gemini. Gemini Notebook is connected by default; switch it off if you keep sensitive material in notebooks.
  4. Vault admins: check the conversation history and deletion settings for each organizational unit before your first Gemini export.
