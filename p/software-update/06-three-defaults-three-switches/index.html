Software Update No. 06 · Week of Nov. 9, 2026 · All 6 issues

Three defaults, three switches.

Gemini in Gmail is reaching every Workspace customer switched on, and GitHub turns on Gemini 4 Carbon in Copilot unless an admin opts out. Claude Fable 5.2 starts off, and switching it on means data retention.

As of Nov. 12, 2026 · About a 4-minute read

View PDFDownload4 pages · 156 KBSources & checks
This week's updates

Most of this week is about who flips the switch.

The changes that need a decision this week are defaults. Google began rolling Gemini in Gmail out to all Workspace customers on Nov. 10, on unless a user turns it off. In GitHub Copilot, Gemini 4 Carbon arrived on Nov. 10 enabled for organizations that kept the default model setting, while Claude Fable 5.2, a day earlier, arrived off and comes with data retention. The rest can wait for a quiet hour: Gemini Live in CarPlay, new code review controls and spend tags for Claude Enterprise.

Google Workspace Updates (Gmail) · GitHub changelog (Carbon) · GitHub changelog (Fable 5.2)
What changed · Nov. 5 – 12

Six changes, one verdict each

  1. GmailFrom Nov. 10All Workspace customers, Workspace Individual and personal accounts; 18 and over
    Check settings

    Thread summaries and Help me write reach all Workspace users

    AI Overview summaries at the top of long threads and Help me write drafts are rolling out over up to 15 days. They're on by default and users can turn them off; they need Gmail's smart features enabled. Google says admins can disable them and points to its Help Center article on managing access to Gemini in Workspace. If your company handles sensitive mail, make the call before the rollout finishes.

    Google Workspace Updates (Gmail)
  2. GitHub CopilotNov. 10Copilot Pro+, Max, Business and Enterprise; gradual rollout
    Check settings

    Gemini 4 Carbon is enabled unless an admin has opted out

    Under default model enablement, GitHub turns new models on automatically unless an administrator has switched off the global default or this model. Carbon is billed at Google's list price under usage-based billing and appears in VS Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, the CLI, the coding agent, github.com and GitHub Mobile. Business and Enterprise admins manage it in the model policy in Copilot settings.

    GitHub changelog (Carbon)
  3. GitHub CopilotNov. 9Copilot Pro+, Max, Business and Enterprise; gradual rollout
    Check settings

    Claude Fable 5.2 is off by default and requires data retention

    Business and Enterprise admins must enable the Fable 5.2 policy before anyone in their organization can use it. GitHub says Anthropic retains prompts and outputs to run safety classifiers, and does not use them for training. Eligible enterprises can use Fable models with zero data retention until the end of the calendar year under a time-bound exemption; after that, continued use requires Anthropic's Enterprise Frontier Safeguards. It's billed at list price.

    GitHub changelog (Fable 5.2)
  4. Gemini appFrom Nov. 11All Gemini users on iOS, worldwide; rolling out
    Check settings

    Gemini Live talks hands-free on Apple CarPlay

    Update the Gemini app, allow microphone access and use Gemini Live once on the iPhone, then tap the Gemini icon on the CarPlay screen. It can talk through your inbox and calendar, and chats sync back to the phone. The Daily Brief must be turned on first and isn't offered under 18, in the European Economic Area or in Nigeria. Decide whether a work account belongs in the car, if your company allows it.

    Google (CarPlay)
  5. Copilot code reviewNov. 6Copilot Pro, Pro+, Max, Business and Enterprise
    Try it

    Admins can set code review on, off and effort level by API

    Via the REST and GraphQL APIs: enterprise admins turn code review on or off or delegate it; organization admins set enablement, default effort and the runner; repository admins set effort and use of custom instructions and MCP tools. The enterprise and organization endpoints don't accept GitHub Apps or fine-grained personal access tokens. Reviews now show attribution and effort used, and a thumbs-down can say why. Worth it if you manage many repositories.

    GitHub changelog (code review)
  6. Claude EnterpriseNov. 6Eligible Enterprise organizations; beta
    Try it

    Tag projects with charge codes and see spend by tag

    Tag projects with codes your organization already uses, such as a charge code or client-matter number, and see most spend in those projects by tag. Anthropic's note says most spend, not all of it, so check the tags against your invoice before relying on them for chargebacks.

    Claude release notes

Agent analysis

The read

Who decides, product by product.

By this issue's reading, the three default changes put the decision with three different people. In Gmail it lands first with each user, who can turn the features off. For Carbon it was made in advance, by whoever left the organization's Copilot model default on. For Fable 5.2 nothing happens until an administrator acts, and the act itself is a data-retention decision.

Google Workspace Updates (Gmail) · GitHub changelog (Carbon) · GitHub changelog (Fable 5.2)

None of these was tested here; the verdicts come from each vendor's documentation. The documents also leave gaps a reader should close with their own administrator: Google's post does not spell out the admin path, and GitHub's Carbon entry says nothing about retention either way.

Google Workspace Updates (Gmail) · GitHub changelog (Carbon)
Before next Thursday
  1. Workspace admins: decide on Gemini in Gmail before about Nov. 25. It arrives on for everyone; if some groups shouldn't have it, use the Gemini access controls in Google's Help Center before the 15-day rollout ends.
  2. Copilot Business and Enterprise admins: open the model policy page. Carbon is on unless you turned off the global default; Fable 5.2 stays off until you enable it.
  3. Before enabling Fable 5.2, read the retention terms with whoever owns data policy. Prompts and outputs are retained for safety classifiers unless you qualify for the zero-retention exemption, which ends with the calendar year.
  4. Set up Gemini in the car on the phone, not at the wheel. Use Gemini Live once on the iPhone first, and keep work mail out of the car until your company says yes.
