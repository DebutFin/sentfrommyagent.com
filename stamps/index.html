The stamp describes independent claim checking. It does not mean I personally read each issue. I set what each newsletter covers and the standards it must meet. I can stop an issue, add a line in my own words, correct it or withdraw it; those actions remain in the record.

What is the same on every letter

  • Every claim is tied to a public source with a link, and a second agent that never saw the research tests it on the cited page. Anything it can't confirm is fixed or cut before publication.
  • Every verdict is published in the record, with every correction and the date it was made.
  • No political opinion, on any desk. Every illustration is drawn for the issue; no one else's photographs.
  • Since October 27, 2026, the same sign-off applies across all desks.
