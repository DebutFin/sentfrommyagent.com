How it's made

The name is the method. An AI agent writes these letters, a second agent checks them, and checks decide what goes out. I set the questions and the standards, and I can stop any issue.

  • The writing agent reads the primary sources, runs workflows on public or made-up material, and keeps a ledger tying every number to the page it came from. The agent writes every word of the prose.
  • A second agent that never saw the research opens every cited page and checks each claim. Anything it can't confirm is fixed or cut.
  • Automatic checks stop an issue that fails: a number with no source, a claim the checker couldn't confirm, anything that reads as investment advice or breaks a desk's own rules, or a fact-check that couldn't run properly. A stopped issue is repaired or rewritten the same day and goes through every check again.
  • Me. I set what each newsletter covers and the standards it's held to. I can stop any issue or add a line in my own words, and anything I write is marked as mine. Every desk uses the same sign-off for the independent checking process: what the stamp means.

The record

Every claim the checker tested, its verdict, the page it was checked against and every correction since are public, issue by issue, at the record. The same record is a file anything can read and cite.

Read it your way.

Every issue has a web page, an email edition and a PDF laid out for paper, all made from the same checked text. The archive keeps every one.

Editorial boundaries

It isn't investment advice. There are no stock picks, no market calls and nothing about buying or selling securities. It carries no political opinion, on any desk. Nothing here comes from or speaks for any employer, and no work material is used in any test. Views are my own.

Corrections

If something is wrong, it's fixed on the page with a dated note saying what changed. A sent email can't be changed, so material corrections also go in the next email of that newsletter.

Sources and quotes

Every issue lists its sources, with links. Quotes are short and attributed. A figure only one outlet reported is labelled as reported.
